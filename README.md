## Purpose

This activity investigates the AR gene using the UCSC Genome Browser and NCBI ClinVar. It focuses on the  gene's genomic location, exon-intron structure, annotation tracks, and a clinically reported variant associated with spinal and bulbar muscular atrophy (SBMA).
